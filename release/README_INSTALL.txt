====================================================
 SIET OVERWATCH - STUDENT AGENT v2.0
 Installation & Usage Guide
====================================================

REQUIREMENTS:
  - Windows 10 or Windows 11 (64-bit)
  - Active internet connection to teacher's server
  - Your Student Roll Number and Password

HOW TO INSTALL (One-Time Setup):
1. Double-click student_agent.exe
2. If Windows SmartScreen appears, click "More info" -> "Run anyway"
3. Enter your Teacher's Server IP (ask your teacher for this)
4. Enter your Student Roll Number / Username
5. Enter your Password
6. Enter the Exam ID (your teacher will give you this)
7. The exam portal will automatically open in your browser

AFTER FIRST RUN:
  - The agent saves your server IP and installs itself to Windows Startup.
  - Future exams: the agent will start automatically when you turn on your PC.
  - If the teacher's IP changes, the agent will ask you to re-enter it.

DURING EXAM:
  - Do NOT close the black terminal window (that is the monitoring agent)
  - Do NOT switch to other browser tabs
  - Do NOT plug in USB drives
  - Do NOT connect a second monitor

If you have any issues, contact your IT administrator.
